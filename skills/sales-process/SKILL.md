# 销售流程技能 (Sales Process)

## 触发场景
- "帮我看看XX客户的销售阶段"
- "如何跟进XX客户？下一步该做什么？"
- "XX客户说要对比一下，怎么应对？"
- "帮我生成客户拜访计划"

## 销售阶段与关键动作

### 标准销售流程（6阶段）

| 阶段 | 目标 | 关键动作 | AI 可提供的帮助 |
|------|------|---------|---------------|
| **1. 线索开发** | 找到潜在客户 | 行业扫描、线索评分 | 行业分析、相似客户推荐 |
| **2. 需求分析** | 了解客户痛点 | 初次沟通、需求调研 | 生成调研提纲、竞品分析 |
| **3. 方案制定** | 提供解决方案 | 方案撰写、ROI测算 | 生成方案文档、效果预估 |
| **4. 商务谈判** | 达成合作意向 | 报价、合同条款 | 谈判话术、合规检查 |
| **5. 签约上线** | 完成签约 | 合同签署、账户开通 | 合同模板、上线Checklist |
| **6. 持续服务** | 客户成功 | 效果优化、定期回访 | 自动报告、健康度监控 |

### 客户拜访准备

当用户要拜访客户时，自动准备以下材料：
1. **客户近况摘要**：近30天消耗、趋势、异常 → `mcp__crm_data__get_customer_detail`
2. **行业动态**：行业政策、新产品 → `mcp__ad_knowledge__search_ad_knowledge`
3. **拜访建议**：3个可聊的话题 + 2个要回避的问题
4. **行动清单**：拜访后需要跟进的事项

### 异议处理

常见异议及应对：
- "太贵了" → 展示ROI数据，对比竞品性价比
- "效果不好" → 诊断投放问题，给出优化方案，展示相似客户成功案例
- "先看看" → 创造紧迫感（限时优惠、竞品动态）
- "已经有供应商了" → 差异化优势分析，渐进式切入

## 输出规范
- 拜访准备材料保存为 Markdown 文件
- 谈判话术用对话体呈现
- 行动清单含优先级和截止时间
