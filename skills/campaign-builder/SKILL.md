# 智能投放计划搭建

## 触发
- "帮我新建一个千川投放计划"
- "给XX客户搭一个引擎信息流计划"
- "这个计划怎么设置定向？"

## 方法论

### 1. 计划要素确认
调 `ad_platform__get_account_info` 获取可用预算和余额 → 确认: 产品线/目标/预算/投放周期

### 2. 自动推荐
- **定向**: 调受众画像 → 推荐相似人群包 + Lookalike + 兴趣标签组合
- **素材**: 调 `creative_library__search_top_ctr(industry)` 获取行业TOP素材
- **出价**: 根据转化目标和行业benchmark推荐初始出价
- **预算**: 日预算 = 目标CPA × 预期转化数 × 1.3（冷启动系数）

### 3. 生成计划草稿
Write 工具保存到 `workspace/campaigns/{customer}_{date}.md`

## 输出格式
```
## 投放计划草稿 — {客户}
- 产品线: 千川
- 目标: 激活, 目标成本 ¥50
- 日预算: ¥500 (冷启动期建议 ¥650)
- 定向: 25-40岁男性, 一线城市, 游戏兴趣, Lookalike 5%
- 出价: oCPM, 初始出价 ¥55
- 素材: 推荐3套 (CTR>行业均值)
- 预计冷启动期: 1-3天
```
