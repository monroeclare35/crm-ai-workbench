# AIGC 创意生成

## 触发
- "帮我写10条千川文案"
- "给XX产品生成视频脚本"
- "这个标题怎么优化？"
- "生成一批搜索广告关键词"

## 方法论

### 1. 创意要素提取
生成前先确认：产品名、核心卖点、目标人群、投放产品线、数量、字数限制。

### 2. 按产品线差异化生成
- **千川短视频**: 前3秒钩子 + 痛点场景 + 产品解决方案 + 限时优惠 + CTA，15-30秒
- **搜索广告**: 标题≤30字 + 核心关键词前置 + 数字卖点 + 品牌名
- **引擎信息流**: 原生感强 + 软植入 + 三段式（共鸣→反转→产品）
- **穿山甲**: 短平快 + 视觉冲击 + 前三帧定生死

### 3. 创意模板库
调 `creative_library__search_templates(industry, product)` 获取行业TOP素材模板

### 4. 合规检查
生成后调 `compliance__check(text, product)` 过滤禁用词

## 输出格式
```
## 生成结果 (N条)
### 素材1 — [类型]
标题: xxx
文案: xxx
适用: [千川/搜索/引擎]
预估CTR: [参考值]
```
