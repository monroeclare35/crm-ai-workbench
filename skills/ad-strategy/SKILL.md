# 广告投放策略技能 (Ad Strategy)

## 触发场景
- "怎么提升XX客户的ROI？""消耗上不去怎么办？"
- "帮我给XX客户出一个投放方案"
- "oCPM和oCPC应该怎么选？""千川和引擎哪个更适合？"
- "XX行业应该怎么投？"

## 分析方法论

### 1. 投放诊断流程（DADI框架）

**Data → Analyze → Diagnose → Improve**

收到策略请求时，按顺序执行：
1. **获取客户数据** → `mcp__crm_data__get_customer_detail`
2. **获取消耗数据** → `mcp__crm_data__query_consumption`（近90天，按天）
3. **获取行业基准** → `mcp__ad_knowledge__search_ad_knowledge(query="行业benchmark", category="strategy")`
4. **对比诊断** → 将客户数据与行业基准逐项对比，找出差距最大的环节
5. **策略生成** → 针对瓶颈环节给出具体优化建议

### 2. 出价策略选择

| 策略 | 适用场景 | 前提条件 | 优势 | 劣势 |
|------|---------|---------|------|------|
| oCPM | 以转化为目标，有充足转化数据 | 日转化 ≥ 20个 | 成本稳定，跑量强 | 学习期波动大 |
| oCPC | 以引流为目标，转化数据不足 | 无硬性要求 | 点击可控 | 转化可能波动 |
| 自动出价 | 中小客户，缺优化人力 | 预算 ≥ 500/天 | 省心 | 可能超成本 |
| 规则出价 | 大客户，严控成本 | 有历史数据参考 | 完全可控 | 跑量受限 |

### 3. 创意优化诊断
从以下维度逐一评估：
- **素材新鲜度**：近7天是否有新素材上线？
- **CTR 健康度**：是否高于行业平均水平？
- **素材多样性**：视频/图片/文案种类 ≥ 3种？
- **落地页体验**：加载速度 < 3秒？转化路径清晰？

### 4. 产品线选择
根据客户行业和目标选择最适合的产品组合：
- **电商** → 千川（直播+短视频）+ 引擎（品牌）
- **游戏** → 引擎 + 穿山甲（流量广）
- **教育** → 千川（社交裂变）+ 搜索（精准意图）
- **B2B** → 引擎 + 搜索（决策链长，需要精准）

## 关键原则
- **以数据说话**：所有建议必须有数据支撑
- **分优先级**：按"预期效果 × 实施难度"排序，优先推荐高效果低难度的
- **给出预期**：每条建议附预期效果范围
- **可落地**：每条建议销售可以直接跟客户沟通
