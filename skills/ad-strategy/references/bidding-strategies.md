# 出价策略参考

## oCPM (Optimized Cost Per Mille)

- **适用**: 有明确转化目标和充足数据的广告主
- **门槛**: 日转化 ≥ 20 个
- **学习期**: 1-3 天，期间成本可能波动
- **优势**: 转化成本稳定，跑量能力强
- **劣势**: 量小/数据少的客户学习困难

## oCPC (Optimized Cost Per Click)

- **适用**: 以引流为目标，转化数据不足的广告主
- **门槛**: 无硬性要求
- **优势**: 点击成本可控，适合新账户冷启动
- **劣势**: 转化量可能波动，需要持续优化

## 自动出价

- **适用**: 中小客户，缺乏优化人力
- **门槛**: 日预算 ≥ ¥500
- **优势**: 省心省力，系统自动优化
- **劣势**: 可能成本超预期，缺乏透明性

## 规则出价

- **适用**: 大客户，对成本有严格管控
- **门槛**: 有充分的历史数据参考
- **优势**: 成本完全可控，透明
- **劣势**: 跑量受限，需要频繁人工调整

## 选择决策树

```
转化数据是否充足（日转化≥20）？
├── 是 → 转化目标是否明确（下单/付费）？
│   ├── 是 → oCPM
│   └── 否 → oCPC
└── 否 → 预算是否 ≥ ¥500/天？
    ├── 是 → 自动出价（让系统学习）
    └── 否 → oCPC（积累数据后升级oCPM）
```
