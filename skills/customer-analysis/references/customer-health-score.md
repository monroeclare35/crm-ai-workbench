# 客户健康度评分模型

## 评分维度与权重

| 维度 | 权重 | 满分条件 | 评分标准 |
|------|------|---------|---------|
| 消耗稳定性 | 25% | 近3月消耗标准差/均值 < 0.15 | 0.15-0.25 → 15分, 0.25-0.35 → 8分, >0.35 → 3分 |
| ROI水平 | 25% | ROI ≥ 行业平均 × 1.2 | 行业平均的80-120% → 15分, 60-80% → 8分, <60% → 3分 |
| 回款及时性 | 15% | 无逾期欠款 | 逾期≤7天 → 10分, 7-30天 → 5分, >30天 → 0分 |
| 服务满意度 | 15% | 满意度调查 ≥ 4.5/5 | 4.0-4.5 → 10分, 3.0-4.0 → 5分, <3.0 → 0分 |
| 产品广度 | 10% | 使用 ≥ 3个投放产品 | 2个 → 6分, 1个 → 3分 |
| 合同续签 | 10% | 合同有效期 ≥ 6个月 | 3-6月 → 6分, 1-3月 → 3分, <1月 → 0分 |

## 评级阈值

- **健康 (Healthy)**: 总分 ≥ 80 — 正常维护
- **关注 (Warning)**: 总分 50-79 — 需主动干预
- **风险 (Risk)**: 总分 < 50 — 立即行动，升级汇报
