# 客户分析技能 (Customer Analysis)

## 触发场景
- "XX客户最近怎么样？""帮我看看XX客户"
- "分析一下XX客户的消耗趋势"
- "帮我准备XX客户的拜访材料"
- "哪些客户最近有问题？""有没有流失风险的客户？"
- "华东区哪些客户消耗下降了？"

## 分析方法论

### 1. 客户画像解读
当用户询问某个客户时，按以下框架组织信息：
- **基础信息**：公司名、行业、规模、区域、客户等级
- **合作概况**：首次合作时间、合同状态、服务团队
- **投放概况**：主要投放产品、主力账户、近30天消耗
- **趋势判断**：消耗是上升/稳定/下降？ROI 是改善/恶化？
- **近期事件**：最近的服务记录、投诉、合同变更

**执行步骤**：
1. 调用 `mcp__crm_data__get_customer_detail(customer_id=...)` 获取客户全貌
2. 调用 `mcp__crm_data__query_consumption(customer_ids=[...], start_date=..., end_date=..., group_by="day")` 获取趋势
3. 如果用户关心行业对比，调用 `mcp__ad_knowledge__search_ad_knowledge(query="行业benchmark", category="strategy")`

### 2. 消耗趋势分析
1. 拉取近90天按天消耗数据
2. 计算近7天 vs 前7天的变化百分比
3. 识别拐点：哪天开始变化？搜索那天前后的相关事件
4. 结合行业数据和客户自身业务周期判断是否正常
5. 如果不正常，给出具体的影响因素假设

### 3. 健康度评估
使用客户健康度评分模型：
- 消耗稳定性 (25分)：近3个月消耗标准差/均值 < 0.15 满分
- ROI 水平 (25分)：高于行业平均满分
- 回款及时性 (15分)：无欠款满分
- 服务满意度 (15分)：评分 >= 4.5 满分
- 产品使用广度 (10分)：使用 >= 3 个产品满分
- 合同续签状态 (10分)：合同有效期 > 6个月满分
综合给出 healthy(>=80) / warning(50-79) / risk(<50) 的评级。

### 4. 流失预警
检查客户是否存在以下信号（命中≥2个标记为"流失风险"）：
- 消耗连续2个月下降超过30%
- ROI 持续低于行业平均水平
- 近30天无新增投放计划
- 服务工单增加或满意度下降
- 关键对接人变更
- 合同即将到期（<3个月）

## 输出规范
- 使用结构化格式呈现（分节、分点）
- 关键数字加粗突出
- 策略建议必须具体可操作
- 如有异常，给出"可能原因 + 建议动作"
- 使用 Markdown 表格展示对比数据
