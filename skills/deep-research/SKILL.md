# 深度调研技能 (Deep Research)

## 触发场景
- "帮我研究一下XX行业的广告投放趋势"
- "做一个XX竞品的分析报告"
- "深度调研XX市场的机会和挑战"
- "分析一下最近的政策变化对广告行业的影响"

## 执行流程

### 阶段1：任务分解（Decomposition）

将用户的研究主题拆分为 3-5 个独立子方向，每个子方向可独立调研。

**示例**：主题="教育行业2026年数字广告投放趋势"
- 子方向1：教育行业广告市场规模与增长数据
- 子方向2：主要投放平台（千川/引擎/搜索）的产品变化与策略调整
- 子方向3：教育行业广告政策与合规动态（2025-2026）
- 子方向4：头部客户案例与ROI表现
- 子方向5：竞争格局变化与未来预测

**分解原则**：
- 每个子方向独立、可并行
- 覆盖"数据 + 政策 + 案例 + 趋势"四个维度
- 子方向之间互不依赖

### 阶段2：并行调研（Parallel Research）

对每个子方向独立调研：

1. 使用 `mcp__ad_knowledge__search_ad_knowledge` 搜索广告知识库
2. 使用 `mcp__document__search_documents` 搜索内部文档
3. 使用 Bash 工具执行 web 搜索（如 curl）获取外部信息
4. 对搜索结果中不够详细的内容，用 `get_knowledge_detail` 获取完整内容
5. 如果一个方向的信息不够，调整搜索关键词再试

**每个子方向的输出**：500-1000字的调研笔记 + 信息来源列表

### 阶段3：交叉验证（Cross-Validation）

1. 检查不同子方向的结果是否一致
2. 标注有矛盾或可疑的信息点
3. 对关键数据点进行二次确认
4. 标注信息来源的权威性（官方文档 > 行业报告 > 媒体报道 > 个人经验）

### 阶段4：报告合成（Synthesis）

将各子方向结果合成为结构化报告：

```markdown
# {调研主题}

## 执行摘要 (Executive Summary)
（200-300字概括：核心发现 + 关键结论）

## 一、市场概况
（市场规模、增长趋势、关键驱动因素）

## 二、平台与产品分析
（各投放平台变化、新产品功能、策略调整）

## 三、政策与合规
（监管动态、合规要求、对业务的影响）

## 四、案例研究
（2-3个代表性案例，含数据和关键启示）

## 五、竞争格局
（主要玩家、差异化策略、机会窗口）

## 六、建议与行动项
（按优先级排列，含可行性评估）

## 资料来源
（列出所有引用的来源和链接）
```

## 质量检查清单

- [ ] 每个数据点标注来源
- [ ] 有矛盾的数据点已标注
- [ ] 结论有直接证据支撑
- [ ] 建议具体可操作，不泛泛而谈
- [ ] Markdown 格式正确，含目录

## 时间管理

- Quick：跳过阶段3交叉验证，30秒内完成（适合简单调研）
- Standard：四阶段完整执行，2-5分钟（默认）
- Comprehensive：每个子方向深度挖掘，5-10分钟（重大决策）
