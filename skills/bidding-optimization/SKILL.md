# 智能出价优化

## 触发
- "ROI从X降到Y，怎么回事？"
- "应该用oCPM还是自动出价？"
- "激活成本超了，怎么降？"
- "新建投放计划，出价设多少？"

## 方法论

### 1. ROI 下降诊断（三步拆解）
调 `ad_platform__query_metrics(compare='wow')` → 逐项检查:
1. CTR 是否下降？→ 素材疲劳（调 `creative_library__check_freshness`）
2. CVR 是否下降？→ 落地页/受众匹配问题
3. CPA 是否上升？→ 竞价环境变激烈 or 出价策略不合理

### 2. 出价策略选择
- 日转化≥20 → oCPM（成本稳定）
- 新账户/转化少 → oCPC冷启动 → 积累数据后转oCPM
- 缺优化人力 → 自动出价（但要监控上限）
- 严控成本 → 规则出价 + 预算上限

### 3. 冷启动建议
新计划前3天: 预算设为日常1.5倍 → 放宽定向 → 至少5套素材 → 不频繁调整

## 输出格式
```
## 出价诊断 — {客户/计划}
ROI变化: 2.5→1.8 (-28%)
拆解: CTR -12%(素材疲劳) + CVR 持平 + CPA +18%(竞价变激烈)
建议:
1. [紧急] 更新3套新素材(现有素材已跑量>2周)
2. [短期] 切换到oCPM, 目标成本下调10%
3. [中期] 测试新定向包, 拓展相似人群
```
